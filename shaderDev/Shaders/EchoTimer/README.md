# EchoTimer

> 这是旧版外轮廓概念稿。当前正式效果已改为实体表面侵蚀与回响裂隙叠加，三维预览及接入说明见 [VoidFlame](../VoidFlame/README.md)。

回响计时器附着效果的 GLSL Canvas 概念原型。中心的暗色剪影代表受到 `ECHO_TIMER` 的目标实体，实体下方的程序化星空和外侧的焰形描边表现虚空侵蚀感。

## 预览

在 VSCode 中打开 `main.frag`，通过命令面板运行 **Show GLSL Canvas**。

## 视觉状态

- 实体外侧的双重焰形扰动描边：目标已经被虚空标记。
- 内层 `0x5500AA` 焰型对应 `VOID_STRIKE`，外层 `0x8000FF` 焰型对应存储回响伤害。
- 两层火舌分别计算长度、尖端和亮度，互不混色。
- 火舌的长度和摆动：表现虚空侵蚀的动态，而不是火焰燃烧。
- 双层焰型内部的深蓝多层程序化星云与星点：表现轮廓能量内部的虚空空间，不铺满整张背景。
- 实体本身遮住星点，只保留一圈很细的 `VOID_STRIKE` 内缘：模拟正确的渲染层关系。
- `0x5500AA`：对应 `VOID_STRIKE` 层数，控制内层焰型的长度和强度。
- `0x8000FF`：对应实体存储的回响伤害，控制外层焰型和内部星云亮度。

这个原型只表现“拥有 ECHO_TIMER”这一状态，不包含倒计时末尾的爆炸、冲击波或碎片扩散。引爆特效由其他效果负责。

## 交互

- 鼠标横坐标模拟 `VOID_STRIKE` 层数，范围为 `0~50`。
- 鼠标纵坐标模拟存储的回响伤害，顶部为 `1000`，底部为 `0`。
- 伤害输入只将 `1000` 点作为渲染强度上限，实际存储值可以继续增加。
- 没有鼠标输入时默认使用 `25` 层 `VOID_STRIKE` 和 `500` 点存储伤害。

## 迁移到 Minecraft

这个目录只服务于 GLSL Canvas 原型，不会被 Minecraft 资源管线加载。迁移到正式渲染时需要：

1. 将全屏 `gl_FragCoord` 坐标改为实体模型局部坐标或屏幕坐标。
2. 将 `u_time` 替换为 Minecraft 可用的游戏时间，并使用实体 tick 部分值平滑动画。
3. 让渲染层读取 `VOID_STRIKE` 的层数，并将存储伤害汇总后在渲染强度计算处限制到 `0~1000`。
4. 先用焰型遮罩绘制轮廓内部星云，再分别绘制两层焰形边缘，最后让实体模型遮挡轮廓内部。
5. 在 `ECHO_TIMER` 添加或移除时触发附着层的出现和消退状态。
6. 将正式的引爆闪光继续交给现有引爆特效处理，避免两个效果重复表现爆炸。
7. 依据目标渲染层的深度、混合模式和透明度重新调整输出。
