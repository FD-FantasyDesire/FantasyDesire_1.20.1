# 虚空火焰：实体表面侵蚀

正式实现位于 `src/main/resources/assets/fantasydesire/shaders/core/fd_void_flame.{vsh,fsh,json}`，由 `VoidFlameLayer` 记录当前姿态，`VoidFlameRenderer` 在 `AFTER_ENTITIES` 提交。原先的屏幕剪影、遮罩贴图与外轮廓追踪已移除。

## 视觉与输入

- **虚空强袭**：同步属性 `VOID_STRIKE_STACK` 映射为 `sqrt(clamp(层数 / 50, 0, 1))`。稳定的三维噪声阈值随层数推进，紫黑斑块从局部扩张，边缘保持深紫侵蚀前沿，内部有缓慢流动的幽焰。
- **回响积蓄**：同步属性 `TOTAL_ECHO_DAMAGE` 映射为 `伤害 / (伤害 + 120)`。从局部细裂隙逐渐扩展为密集发亮的分叉网络，超过 1000 伤害仍可增长。只影响渲染，不限制实际伤害。
- **新增伤害**：观察到同步伤害增加时触发向上的传播脉冲，单道最长 1.2 秒，最多同时四道。0.3 秒内的新增命中加强最近一道波，不反复重置传播位置。客户端只能观察同步后的合计增量，同一个同步间隔内的多次命中会合并。
- **独立清理**：伤害归零立即清除回响通道，虚空层数归零立即清除侵蚀通道。二者都为零时不再收集模型，没有消退残留或额外引爆动画。
- **时间**：`EffectTime` 是实体 tick 加 partial tick 换算的秒；`EchoPulseAges` 是四道波各自经过的秒数。强度用约 2.5 tick 的指数过渡，暂停时停止推进。

## 独立预览

在仓库根目录运行任意静态文件服务器，例如：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/shaderDev/VoidFlame/preview.html`。服务器必须以仓库根目录为根，页面会直接读取正式 `.vsh` / `.fsh`，仅把版本转换为 WebGL 2 的 GLSL ES 3.00，并补充精度声明。此预览需要 WebGL 2，不能用 GLSL Canvas 直接加载。

可调整两个强度、观察角度和种子，暂停动画，模拟伤害增加或清空。预览使用自行生成的灰蓝棋盘材质与方块人形模型，没有外部纹理或脚本依赖。原始皮肤先写深度，效果层使用 Alpha 混合和小幅多边形深度偏移；这验证表面着色逻辑，不代表 Minecraft 的完整场景验收。

`shaderDev/EchoTimer` 保留为旧外轮廓概念稿，不再对应当前正式效果。

## 渲染边界与验收

- `NEW_ENTITY` 顶点格式与 JSON attributes 一致。`EffectLocalMat` 逆转实体根姿态，得到以实体为锚点的三维场；肢体运动穿过该场产生流动侵蚀，镜头运动不会推动纹理。使用原皮肤的 Alpha 裁切，避免透明部位出现方片。
- 在每帧实体阶段统一刷新原版延迟批次，再绘制受影响模型。深度测试保留、深度写入关闭，因此其他实体、地形与不透明盔甲可以遮住被侵蚀的皮肤。不会透过盔甲强行把基础模型画出来；独立盔甲、手持物与自定义额外模型不会自动染色。
- 覆盖正常 `LivingEntityRenderer` 与玩家，隐藏实体跳过。史莱姆通过 `VoidFlameSlimeOuterLayer` 额外采集 `SLIME_OUTER` 外壳，复用原版动画、尺寸、挤压与纹理 Alpha；内外层共享同一实体的侵蚀强度及回响脉冲。仅向 `SlimeRenderer` 注册该外壳，不影响岩浆怪。其他独立外层及没有使用 `LivingEntityRenderer` 的特殊模型需要自己的接入层。半透明实体及第三方 shader 管线仍需在目标整合包检查合成。
- 末影龙通过仅客户端加载的 `EnderDragonRendererMixin` 接入。在原版 `DragonModel.prepareMobModel` 之后使用同一模型与当前根姿态采集，因此翅膀、头颈、尾部和身体沿用原版动画与纹理。仅采集龙的身体绘制，水晶光束不受影响；死亡消散阶段停止采集，避免填回已消失的部位。没有替换末影龙渲染器；完全绕过原版 `render` 的其他模组龙渲染器仍需独立适配。
- 不持有跨重载的 `ShaderInstance`，每帧通过 getter 获取；每帧清理未提交网格，切换世界清空视觉状态，退出连接释放 GPU 缓冲。不创建全屏颜色/深度目标。
- 需在实际场景检查：1 / 20 / 50 层；10 / 120 / 1000 / 2000 伤害；两个通道单独存在；连续命中与清账；转动镜头、走动和受伤姿态；盔甲、墙后实体和多个重叠目标；F3+T、切换世界与窗口缩放；大量目标时的帧耗时。

当前本机已通过 Java 编译、资源处理、桌面 OpenGL 3.2 的原始 GLSL 150 编译/链接及 WebGL 2 预览。桌面离屏像素检查覆盖了零状态无输出、两通道独立增长、1000 以上继续增长、脉冲结束无残留、透明纹素裁切与远雾隐藏。预览不用于声称实际游戏帧率或第三方兼容性。
