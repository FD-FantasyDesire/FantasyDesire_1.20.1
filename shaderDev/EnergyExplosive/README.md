# EnergyExplosive

EnergyExplosive 是一个独立、无贴图的 GLSL Canvas 单 pass 能量爆破原型。外围的多臂漩涡能量流先旋转并向中心收束，引爆后形成白热核心、带明暗遮蔽的多尺度不规则等离子壳层、前后层次光晕与局部团块，整体呈超新星式立体爆炸；两层不同速度和厚度的冲击波向外传播，同时 28 个无拖尾、无震荡的能量碎屑沿固定随机射线直线喷溅。动画末段完整淡出，可连续循环。

## 运行环境

- 预览目标：VSCode **GLSL Canvas**（扩展 ID：`circledev.glsl-canvas`）。
- 打开 [`main.frag`](main.frag) 后运行 **Show GLSL Canvas**。
- 面向 WebGL 1 / GLSL ES 1.00：不使用 `#version`、`#include`、纹理、导数或现代输出变量，输出为 `gl_FragColor`。
- Shader 完全自包含，不依赖 Minecraft 管线或鼠标输入。

## Uniform 与坐标

```glsl
uniform float u_time;
uniform vec2 u_resolution;
```

坐标按画布短边归一化，在非正方形分辨率下仍保持爆破和震荡环为圆形。时间限制在 4096 秒内，分辨率、半径、周期、线段投影及指数宽度的除数均设有安全下限。

## 双颜色区间

顶部 [`PRIMARY_COLOR`](main.frag:14) 与 [`SECONDARY_COLOR`](main.frag:15) 是整个效果的两个显式颜色入口：前者默认用于高能爆心和内侧，后者默认用于低能外缘、远端冲击波与粒子传播末端。

[`energyPalette()`](main.frag:67) 依据归一化半径并结合局部亮度/能量偏置进行混合。混合区间由 [`COLOR_BLEND_START`](main.frag:16) 和 [`COLOR_BLEND_END`](main.frag:17) 控制：减小起点会让第二颜色更早出现，增大终点会扩大两色渐变过渡。颜色分量使用 0.0–1.0 的线性 RGB 常量，可直接编辑。

## 动画与视觉层次

默认 [`CYCLE`](main.frag:19) 为 1.20 秒：

1. **漩涡汇聚（0%–约 13%）**：外围多臂能量流持续旋转，弯曲的螺旋轨迹逐渐收紧并卷入中心，明显区别于单纯径向缩放。
2. **超新星爆发（约 12%–42%）**：白热球形核心过曝，前后两层不同尺度的噪声等离子壳以径向噪声、低频团块、边缘辉光和中心遮蔽塑造伪 3D 体积；十字星只在引爆瞬间短暂出现，且不含闪电或锯齿径向纹路。
3. **传播（约 12%–76%）**：两道速度、宽度不同的柔和冲击波向外扩散；压缩晕补充厚度而非雷纹。
4. **粒子溅射（约 15%–92%）**：28 个固定循环碎屑仅在引爆后按不同延迟出现，以黄金角覆盖配合稳定随机方向形成非均匀簇与空隙；每颗具有独立速度、寿命、尺寸、亮度和径向阻尼，沿固定射线直线外抛，无线段、彗尾、横向偏转或周期震荡。
5. **衰减（约 76%–98%）**：爆光、震荡环及粒子逐层淡出，周期首尾保持安静背景以隐藏循环接缝。

## 主要可调项

- [`BLAST_RADIUS`](main.frag:20)：颜色径向归一化及爆破参考尺寸。
- [`SHOCK_SPEED`](main.frag:21)：冲击震荡环的外扩速度。
- [`PARTICLE_SPEED`](main.frag:22)：喷射粒子的整体径向速度。
- [`EXPOSURE`](main.frag:23)：最终预览 tone mapping 曝光。
- [`vortexCharge()`](main.frag:109)：控制漩涡臂弯曲、旋转及由外围向中心收束的蓄能形态。
- [`crossStar()`](main.frag:124)：控制引爆瞬间的四向十字星芒、中心高亮和短暂余辉。
- [`ringFbm()`](main.frag:70)：先以 `cos(angle), sin(angle)` 将角度映射到连续环域，再叠加半径和时间漂移；极角跨越 ±π 时噪声坐标保持一致。
- [`supernovaShell()`](main.frag:178)：控制带遮蔽的多尺度等离子壳层与团块。
- [`particleBurst()`](main.frag:137)：固定 28 次编译期循环；可在循环上限处调整粒子数量，但较高数量会增加片元开销。

## 兼容与输出

代码仅使用 GLSL ES 1.00 可用的标量/向量运算、固定循环和 `gl_FragColor`；片元 `highp` 不可用时回退到 `mediump`。最终使用指数 tone mapping 映射到普通 0–1 预览范围；迁移到浮点 HDR/Bloom 管线时可移除该映射并由宿主完成曝光与辉光合成。
