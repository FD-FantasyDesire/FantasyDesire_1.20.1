# 通用评分 SE：心、望

通用 SE 不要求特定刀名，沿用拔刀剑的 SE 经验门槛（80 级），仅主手完好且装有对应 SE 的刀生效。心、望可以同时生效，共享拔刀剑评分；创造模式同样消耗评分。

满足条件时初始为 1 层，每 5 个游戏 tick 心、望分别判定一次，成功增加 1 层，心上限 18 层，望上限 3 层。评级只决定叠层概率；降至 SS 或 S 保留层数，低于 S 清空。

| 评级 | 心：任意层升下一层 | 望：1→2 层 | 望：2→3 层 |
| --- | ---: | ---: | ---: |
| S | 15% | 15% | 7.5% |
| SS | 35% | 35% | 17.5% |
| SSS | 60% | 60% | 30% |

心的概率仅随评级改变，不随层数降低，每次成功增加一层。望的概率为 `评级基础概率 × stack_chance_decay^(当前层数-1)`，默认衰减系数为 0.5，满层不再增长。

心每层减伤 5%，18 层为 90%，每秒每层额外扣 1 分。第 1 层气场不透明度系数为 20%，第 18 层为 100%，中间线性增长，0 层不渲染；火焰透明边缘和雾仍保留。激活时立即显示初始档，后续档位变化在 5 tick（0.25 秒）内以 smoothstep 平滑过渡，中途收到新档位时从当前显示值继续；失效立即清理，不延迟减伤变更。过渡时间取游戏 tick 加 partial tick，与帧率无关，切换世界和退出时清空缓存。望倍率为 `1.25 ^ 层数`，1/2/3 层分别为 1.25/1.5625/1.953125 倍，每层一枚刀环。

望每目标命中按层数请求扣分，每 20 tick 全部命中共用 8 分预算，换刀不会重置。默认评分单位 300，两者满层从满评分 1799 开始，即使不计任何命中加分，40 tick 内最坏扣除自然衰减 40 + 心 54 + 望 24 = 118 分，仍至少 1681 分，高于 SSS 下界 1650，保持 SSS 超过 2 秒。计算保守覆盖窗口交界处三次扣费。

满层不会因评分在 SSS 内降低而降层；但若开始时已在 SSS 下界，自然衰减本身会导致掉级，不能仅凭层数保证 2 秒。受击原生整级扣分、外部扣分、改配置或评分容量不在上述保证内。

以上均为默认值。配置位于存档 `serverconfig/fantasydesire-server.toml` 的 `se.fantasydesire.lc_shin`、`se.fantasydesire.lc_mang` 节，叠层概率键为 `stack_chance_s/ss/sss`，望额外提供 `stack_chance_decay = 0.5`。旧存档需将心的 `reduction_cap` 改为 0.9、望的 `multiplier_base` 改为 1.25；旧 `rank_cost_per_tier` 替换为 `rank_cost_per_stack = 1`，望增加 `rank_cost_per_second_cap = 8`。两者旧 `points_per_tier` 不再使用。本次同步调整了开发存档 `run/saves/新的世界` 对应配置节。

## 结算与生命周期

- 层数由服务端维护为临时加值修改器，自动同步给气场与刀环；重登从 1 层重新累积。
- 心在 `LivingHurtEvent` 的 HIGH 优先级、拔刀剑受击扣分前计算减伤，之后仍保留护甲、抗性等结算。默认减伤上限 90%，不处理绕过无敌保护的伤害（如虚空、`/kill`）。持续消耗每 20 个游戏 tick 结算，保留拔刀剑的自然衰减。
- 望为 `ATTACK_DAMAGE` 添加 `MULTIPLY_TOTAL` 临时修改器：倍率 = `multiplier_base ^ 有效点数`。只乘面板，评级、附魔等额外加值继续由原攻击公式计算。现有技能若从攻击力面板取值，也会随面板变化。
- 望只通过攻击伤害属性修改器增伤，不修改任何伤害事件的伤害数值；不同伤害类型的拔刀剑攻击只要读取面板就获得同一乘区。固定伤害的普通幻影剑不补乘倍率，也不参与评分消耗；读取面板的 `EntityDrive` 和 `EntityFDDriveEx` 保留自然属性加成。
- 伤害事件仅用于有效命中扣分，保留命中加分；反伤、普通幻影剑、普通箭矢、延迟回响通用／魔法引爆、无归属、自身伤害及完全吸收／取消的命中不扣分。近战、自定义直接斩击、面板型剑气与范围攻击共用预算。
- 评级不足 S、经验不足、刀折断、换下主手刀时移除本 SE 的修改器，不改变属性基值或其他来源的修改器；死亡时清理。重新达到条件会自动恢复，不移除刀上的 SE。
- 真正更换主手物品栈清空层数，换另一把同 SE 刀从 1 层开始；同一栈的耐久与 NBT 变化不误清层。换手与攻击前校准，自然评级、同一栈内状态变化最迟下一服务端 tick 校准。

## 验收要点

1. 分别给任意原生拔刀剑与 FantasyDesire 刀装入 SE，经验 79 级不生效，80 级生效；副手与背包不激活。
2. S/SS/SSS 下每 5 tick 概率叠层，心每层概率相同、最多 18 层，望第二层升第三层的概率减半、最多 3 层；降至 SS 或 S 保留，降至 A 清空。心升层时气场透明度平滑渐变，实际减伤立即更新。
3. 只装心，停止攻击观察额外扣分与评级不足 S 后的消散；受击时检查减伤，并确认原有受击扣分仍发生。
4. 近战、自定义类型与面板型剑气命中共享预算，完全吸收不扣分；普通幻影剑不增伤或扣分，任何伤害事件均不补乘倍率。
5. 同时装备两者，检查共享评分；换刀、折断、降经验、死亡、重登后不能残留本 SE 的面板倍率。重新满足条件时可以恢复。
6. 从满评分且两者满层开始，40 tick 不受击、无外部扣分，连续多目标攻击仍保持 SSS；换刀不重置扣分预算，耗耐久不重置层数。
